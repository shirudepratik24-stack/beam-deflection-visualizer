# RecoverAI demo

This repository contains the runnable FastAPI + LangChain application. GitHub is source hosting; run the backend locally or deploy it to a Python host such as Render/Railway for a public working URL.

## Submission links

GitHub: https://github.com/shirudepratik24-stack/Fastapi-

Working demo: deploy this repository with `uvicorn main:app --host 0.0.0.0 --port $PORT` and set `OPENAI_API_KEY` in the host's environment variables.
